Iki uygulama katmani

Detaylandirmanin cogu motora hic dokunmadan yapilabilir. Yalniz en derin 4 madde trace'e yeni alan yakalamayi (ft-performance.js) gerektirir.

Renderer-only

yalnizca js/graphics.js · sifir motor riski

~22 madde. Tum degerler trace/params'ta zaten var; renderer daha derin basar. Yan etki yok, deger degismez. Onerilen ilk adim.

Engine-capture

+ js/ft-performance.js · daha derin

~4 madde. Motorda hesaplanip atilan ara degerleri trace'e yakalar (aksesuar ayrimi, RK45 adaptif, PCHIP). RK45'te degerler ana donguden aktarilir — yeniden hesap yok, deger yine degismez.

Eklenen detay gruplari

Toplam 26 somut ekleme; hicbiri mevcut bir satiri silmez veya sayiyi degistirmez — yalniz ayni hesabin ara adimlarini gorunur yapar.

Direnc zinciri

renderer

theta=atan(grade/100) tek turetim + cos/sin; Crr_eff icinde K1/K2 sayisal ve f faktoru; F_roll & F_grade tam carpim zinciri; F_aero k_aero ara katsayi.

Motor & kinematik

renderer

omega_wheel = v/r_tire ara adimi; N_turbine/N_engine tam sayi ikamesi; i_total zinciri lockup/direct dallarina da.

Konvertor

renderer

Rev-up payi T_eng_net acik; isi reddi alt-terimleri (omega_eng, turbin gucu, ic verim); TC verimi eta=SR*tau; ortak omega_eng satiri.

Disli verimi

renderer

|ln(i_gear)| ve devir-bagimli parantez ayri; nihai eta clamp bilgisiyle.

Esdeger kutle

renderer

Her terim ham_I x carpan^2 = katki tablosu; i_down ve r_tire^2 ayri satir.

Entegrasyon

renderer

Her RK asamasi (v_in, a) cifti; dv agirlikli-toplam sayisal ikame.

Tablolar & C/D

renderer

Dusuk-dal tam tarama tablosu (N|SR|K_pump|excess); C (stall) ve D (~10km/h) TE->DP zincirleri.

Kunye & basliklar

renderer

F_net ayri satir; adim basligina mesafe + adim#; A bolumune eksik sabitler (vites gecis oranlari, maxTime, propshaft orani).

Aksesuar ayrimi

+motor

Fan N^3 vs diger N: ratio, P_fan, P_other, omega, T_loss. (ft-performance.js yakalamasi)

RK45 adaptif

+motor

Hata/tolerans/adim kabul-ret/dt_used + ara-hizlar. Ana donguden AKTARILIR (yeniden hesap yok). (ft-performance.js)

PCHIP komsulari

+motor

Tork/K/tau spline lookup komsu dugumleri + interpolasyon agirligi. (dusuk oncelik, ft-performance.js)

  [1] MOTOR DEVRI VE TORKU

      i_total     = i_gear * i_ps * i_tr * i_axle
                  = 2.2700 * 1.000 * 1.0000 * 5.2900
                  = 12.0083
      N_turbine   = (v / r_tire) * i_total * 60/(2pi)
                  = 1555 rpm

      T_gross     : 1180.0 N.m   (PCHIP tork egrisi @ N)
      T_net       = T_gross - T_aksesuar
                  = 1180.0 - 97.2
                  = 1082.8 N.m

  [2] TORK KONVERTORU (converter mod)

      SR          = N_turbine / N_engine
                  = 1555 / 2100
                  = 0.7406
      tau(SR)     : 1.1000
      K_pump(SR)  : 72.000
      T_pump      = N_engine^2 / K_pump^2
                  = 2100^2 / 72.00^2
                  = 850.7 N.m
      T_turbine   = T_pump * tau
                  = 850.7 * 1.100
                  = 935.8 N.m

      Rev-up      : dN/dt = (T_net - drop - T_pump)/I_eng_rev * 60/(2pi) = 1043.1 rpm/s
      Isi reddi   : 37.42 kW   (TC slip 34.67 + gear-mek 2.76)

  [2b] DISLI VERIMI (calcGearEfficiency)

      eta_gear    = 1 - |ln(i_gear)| * (0.0175 + 2.93e-6 * N_turb)
                  = 0.9819   (N_turb = 1555 rpm)
      T_cikis     = T_cikis(ham) * eta_gear
                  = 935.8 * 0.9819
                  = 918.8 N.m

  [3] CEKIS KUVVETI (tekerlekte)

      F_ham       = T_out * i_gear * i_ps*eta_ps * i_tr*eta_tr * i_ax*eta_ax / r_tire
                  = 20282 N

      F_cekis     : 20282 N   (20.28 kN)

  [4] DIRENC KUVVETLERI

      Crr_eff     = Crr * (1 + K1*v + K2*v^2)
                  = 0.00800 * (1 + K1*6.94 + K2*6.94^2)
                  = 0.00942
      F_roll      = Crr_eff * yuzey * m * g * cos(theta)
                  = 1662 N
      F_aero      = 0.5 * rho * Cd * A * v^2
                  = 0.5 * 1.225 * 0.800 * 8.000 * 6.94^2
                  = 189 N
      F_grade     = m * g * sin(theta)
                  = 8818 N   (egim 5.0%)
      F_direnc    = F_roll + F_aero + F_grade
                  = 1662 + 189 + 8818
                  = 10669 N

  [5] ESDEGER KUTLE VE IVME

      I_eff = SUM(I_k * i_k^2)  — her atalet teriminin katkisi:
        konv-turbin   50.5
        sanziman      28.0
        propsaft      8.4
        transfer      22.4
        aks           1.2
        teker         18.0
        --------------------
        toplam        128.4 kg.m^2

      m_eff       = m + I_eff / r_tire^2
                  = 18000 + 128.4 / 0.5120^2
                  = 18490 kg   (x1.027)
      a           = (F_cekis - F_direnc) / m_eff
                  = (20282 - 10669) / 18490
                  = 0.5199 m/s^2   (0.0530 g)

  [6] SAYISAL ENTEGRASYON (RK4, dt = 0.0100 s)

      k1                     = 0.51994 m/s^2
      k2                     = 0.51993 m/s^2
      k3                     = 0.51993 m/s^2
      k4                     = 0.51992 m/s^2

      dv          : (k1+2k2+2k3+k4)/6 * dt = 0.00520 m/s
      v_sonraki   : v + dv = 6.9496 m/s

    [1]  MOTOR DEVRI VE TORKU
    ──────────────────────────────────────────────────────────────────────────────────
      i_total      = i_gear * i_ps * i_tr * i_axle
                   = 2.2700 * 1.000 * 1.0000 * 5.2900
                   = 12.0083
      omega_wheel  = v / r_tire
                   = 6.9444 / 0.5120
                   = 13.5634 rad/s
      N_turbine    = omega_wheel * i_total * 60/(2pi)
                   = 13.5634 * 12.0083 * 9.54930
                   = 1 555 rpm

      Dusuk-dal eslesme taramasi — excess(N) = T_net - drop - N^2/K_pump^2 :
      ┌───────────┬─────────┬──────────┬────────────┐
      │   N (rpm) │      SR │   K_pump │     excess │
      ├───────────┼─────────┼──────────┼────────────┤
      │       600 │   2.592 │    72.00 │      983.3 │
      │       900 │   1.728 │    72.60 │      899.1 │
      │     1 200 │   1.296 │    73.20 │      784.0 │
      │     1 500 │   1.037 │    73.80 │      639.7 │
      └───────────┴─────────┴──────────┴────────────┘
      -> secilen dal: dusuk (surunme) — min excess vadi tabaninda

      T_gross      : 1 180.0 N.m   (PCHIP tork egrisi @ 2 100 rpm)
      T_aksesuar ayrisimi (fan N^3 + diger N):   « motor yakalamasi »
         ratio     = N/Ngov = 2 100/2 200 = 0.9545
         P_fan     = accFanLoss*ratio^3 = 18.0*0.8697 = 15.66 kW   (kavramali)
         P_other   = accOtherLoss*ratio = 6.0*0.9545 = 5.73 kW
         omega_eng = N*2pi/60 = 2 100*0.104720 = 219.91 rad/s
         T_loss    = (P_fan+P_other)*1000/omega = 21.38*1000/219.91 = 97.2 N.m
      T_net        = T_gross - T_loss
                   = 1 180.0 - 97.2
                   = 1 082.8 N.m

    [2]  TORK KONVERTORU (converter mod)
    ──────────────────────────────────────────────────────────────────────────────────
      SR           = N_turbine / N_engine
                   = 1 555 / 2 100
                   = 0.7406
      tau(SR)      : 1.1000   (PCHIP tork-orani egrisi)
      K_pump(SR)   : 72.000   (PCHIP K-faktoru egrisi)
      TC verimi    : eta = SR*tau = 0.741*1.100 = 0.815   (>1: hidrolik tork cogaltma)
      omega_eng    = N_engine * 2pi/60
                   = 2 100 * 0.104720
                   = 219.91 rad/s
      T_pump       = N_engine^2 / K_pump^2
                   = 2 100^2 / 72.00^2
                   = 850.7 N.m
      T_turbine    = T_pump * tau
                   = 850.7 * 1.100
                   = 935.8 N.m

      Rev-up dinamigi (yuksek dal):
         T_eng_net = T_net - drop - T_pump = 1 082.8 - 30.0 - 850.7 = 202.1 N.m
         dN/dt     = T_eng_net/I_eng_rev * 60/(2pi) = 202.1/1.85 * 9.54930 = 1 043.1 rpm/s

      Isi reddi (TC kaymasi + dishli-mekanik):
         P_TC_slip = T_pump*omega_eng*(1-SR*tau)/1000 = 850.7*219.9*(1-0.815)/1000 = 34.67 kW
         P_turbine = T_turbine*omega_turb/1000 = 935.8*162.87/1000 = 152.41 kW
         P_gear_mek = P_turbine*(1-eta_gear) = 152.41*(1-0.9819) = 2.76 kW
         Isi reddi = P_TC_slip + P_gear_mek = 34.67 + 2.76 = 37.42 kW

    [2b]  DISLI VERIMI (calcGearEfficiency)
    ──────────────────────────────────────────────────────────────────────────────────
         absLn     = |ln(i_gear)| = |ln(2.2700)| = 0.8198
         paren     = 0.0175 + 2.93e-6*N_turb = 0.0175 + 2.93e-6*1 555 = 0.022057
      eta_gear     = 1 - absLn * paren
                   = 1 - 0.8198 * 0.022057
                   = 0.9819   (clamp [0.90, 1.00])
      T_cikis      = T_cikis(ham) * eta_gear
                   = 935.8 * 0.9819
                   = 918.8 N.m

    [3]  CEKIS KUVVETI (tekerlekte)
    ──────────────────────────────────────────────────────────────────────────────────
      F_ham        = T_out * i_gear * i_ps*eta_ps * i_tr*eta_tr * i_ax*eta_ax / r_tire
                   = 918.8 * 2.270 * 1.000*0.9850 * 1.000*0.9800 * 5.290*0.9750 / 0.5120
                   = 20 282 N

      Tutunma      : F_grip = mu*m*tahrik%*g = 0.80*18 000*1.00*9.81 = 141 264 N -> serbest
      F_cekis      : 20 282 N   (20.28 kN)

    [4]  DIRENC KUVVETLERI
    ──────────────────────────────────────────────────────────────────────────────────
      theta        = atan(grade% / 100)
                   = atan(0.0500)
                   = 0.049958 rad (2.862 deg)
         cos(theta) = 0.998752
         sin(theta) = 0.049938
      f (hiz duz.) = 1 + K1*v + K2*v^2
                   = 1 + 0.026909*6.944 + (-0.00018893)*48.225
                   = 1.177757
      Crr_eff      = Crr_static * f
                   = 0.00800 * 1.177757
                   = 0.009422
      F_roll       = Crr_eff * yuzey * m * g * cos(theta)
                   = 0.009422 * 1.000 * 18 000 * 9.81 * 0.99875
                   = 1 662 N
         k_aero    = 0.5*rho*Cd*A = 0.5*1.225*0.800*8.000 = 3.9200
      F_aero       = k_aero * v^2
                   = 3.9200 * 48.225
                   = 189 N
      F_grade      = m * g * sin(theta)
                   = 18 000 * 9.81 * 0.04994
                   = 8 818 N
      F_direnc     = F_roll + F_aero + F_grade
                   = 1 662 + 189 + 8 818
                   = 10 669 N

    [5]  ESDEGER KUTLE VE IVME
    ──────────────────────────────────────────────────────────────────────────────────
      F_net        = F_cekis - F_direnc
                   = 20 282 - 10 669
                   = 9 614 N

      I_eff = SUM( I_k(ham) * carpan^2 ) — her terimin acik katkisi:
        terim           I_ham  carpan^2                  katki
        ----------------------------------------------------
        konv-turbin      0.35  i_total^2 = 144.199       50.47
        sanziman         1.00  i_down^2 = 27.984         27.98
        propsaft         0.30  i_down^2 = 27.984          8.40
        transfer         0.80  i_axle^2 = 27.984         22.39
        aks              1.20  1 = 1.000                  1.20
        teker           18.00  1 = 1.000                 18.00
        ----------------------------------------------------
        toplam                                          128.44 kg.m^2
         i_down    = i_ps*i_tr*i_axle = 5.290  (sanziman/propsaft carpani)
         r_tire^2  = 0.5120^2 = 0.2621 m^2  (m_eff boleni)
      m_eff        = m + I_eff / r_tire^2
                   = 18 000 + 128.44 / 0.2621
                   = 18 490 kg   (x1.0272)
      a            = F_net / m_eff
                   = 9 614 / 18 490
                   = 0.5199 m/s^2   (0.0530 g)

    [6]  SAYISAL ENTEGRASYON (RK4, dt = 0.0100 s)
    ──────────────────────────────────────────────────────────────────────────────────
      Her asama, degerlendirildigi giris hizinda a(v):
      k1    @ v_in=6.9444 m/s  ->  a = 0.51994 m/s^2
      k2    @ v_in=6.9470 m/s  ->  a = 0.51993 m/s^2
      k3    @ v_in=6.9470 m/s  ->  a = 0.51993 m/s^2

                   = (0.51994 + 2*0.51993 + 2*0.51993 + 0.51992)/6 * 0.0100
                   = 0.005199 m/s
      v_sonraki    = v + dv
                   = 6.9444 + 0.005199
                   = 6.9496 m/s
